## Day 1 (Tuesday) — GitHub Scanner + Deploy Backend
**Time: ~5 hrs**

### Build GitHub repo scanner (IN PROGRESS)
Claude Code prompt:
```
Read CLAUDE.md. Build the GitHub repo scanner:

Phase 1: app/services/content_analyzer.py
- Pure functions that glob-match file paths against compliance patterns
- Keyword-match file contents against purpose/evidence signals
- Maps findings to ScannerOutput boolean fields
- Uses the mapping table from CLAUDE.md Section 8
- No HTTP calls — just takes file tree + file contents as input

Phase 2: Port requirements_parser from tmp/ to app/scanners/
- Use Pydantic DetectedFramework instead of dataclasses
- Keep the same 30+ framework signature database

Phase 3: app/services/github_scanner.py
- Fetches repo tree via GET /repos/{owner}/{repo}/git/trees/{branch}?recursive=1
- Reads key files via GET /repos/{owner}/{repo}/contents/{path}
- Decode base64 content from GitHub API responses
- Fall back to 'master' if 'main' branch doesn't exist
- Wire content_analyzer + requirements_parser into full ScannerOutput
- Use httpx for async HTTP. Handle rate limits gracefully.

Phase 4: POST /api/v1/scans/repo endpoint
- Chains GitHubScanner → RequirementsParser → RiskClassifier → ComplianceEngine
- Returns full compliance report JSON per Section 7 of CLAUDE.md
- Synchronous for now (no background jobs)

Use /tdd workflow for all phases.
```

- [ ] Verify `/health` and `/docs` at public URL
- [ ] Test `/api/v1/scans/repo` with a real public GitHub repo
